# Applied Bioinformatics & Genomics Scripts

This repository contains custom R and Python scripts developed for biological data processing and bioinformatics pipelines:

- **RNA-Seq / Gene Expression Analysis (`rna_seq_deseq2_analysis.r`)**: Differential expression pipeline using DESeq2 workflow in R.
- **Data Processing & Genomics (`bioinformatics_data_processor.py`)**: Python script for sequence parsing, GC content calculation, and expression metric filtering.
- **Skills & Tools**: Python (`pandas`, `numpy`), R (`DESeq2`, `ggplot2`), Linux/Bash.
